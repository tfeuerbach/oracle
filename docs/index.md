# Oracle

**A Discord bot that transcribes every video in your server and makes them searchable by what was said.**

Ever tried to find that one video someone posted months ago? You remember *what was said* but not who sent it or when? Oracle solves that.

## How it works

1. **Add Oracle** to your Discord server
2. **Pick which channels** to monitor during setup
3. Oracle **automatically transcribes** every video posted — file uploads, YouTube links, Reddit clips, and more
4. **Search by memory** — type `/search something funny about cats` and Oracle finds matching videos instantly

## Features

- **File attachments** — MP4, WebM, MOV, AVI, MKV, and more
- **URL videos** — YouTube, Reddit, Vimeo, Instagram, Facebook, Twitter/X, TikTok, Twitch, Dailymotion, Streamable
- **Full-text search** with ranked results and highlighted snippets
- **Semantic search** — find videos by meaning, not just exact keywords
- **Per-server privacy** — each server's data is completely isolated
- **Concurrent processing** — transcribes up to 5 videos simultaneously
- **Backfill** — index every video ever posted in a channel, not just new ones
- **Live monitoring** — new videos are transcribed automatically as they're posted
- **Full transcription** — long videos are chunked and transcribed completely with no truncation (configurable max duration, default 1 hour)
